  • 토스페이: 60달러 이상 결제 시 4달러 즉시 할인
  • 카카오페이: 70달러 이상 결제 시 5달러 즉시 할인
  • 네이버페이: 80달러 이상 결제 시 6달러 즉시 할인
  • 신한 / KB국민 / 삼성 / 농협카드: 100달러 이상 결제 시 8~10달러 즉시 청구할인

3. 직구 고수들의 5중 중복 할인 결제 공식

➔ 3단계: 주문서 화면에서 위 표의 '공용 프로모션 코드' 입력

➔ 4단계: '코인 보유분 자동 사용' 체크 (1~15% 추가 감면)

➔ 5단계: 결제 단계에서 '카드사 또는 간편결제 즉시 할인' 선택
